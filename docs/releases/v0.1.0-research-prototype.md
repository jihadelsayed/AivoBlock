# AivoBlock v0.1.0 — Research Prototype (2026)

**Release type:** research prototype prerelease; not a production blockchain, token offering, scientific preprint or peer-reviewed publication.

**Project:** [AivoBlock](https://github.com/jihadelsayed/AivoBlock)  
**Research direction:** verifiable, partitioned useful integer AI computation on a permissioned blockchain.  
**Attribution:** Sayed Jihad ElSayed and AivoBlock contributors (see Git history).

## What is implemented

- Rust node runtime and authenticated, encrypted validator-to-validator communication.
- Haskell deterministic ledger settlement and Rust cross-validation.
- Python worker for partitioned deterministic AI tasks; QMLP-V1 uses integer-only quantized inference.
- Three-node private Docker testnet with finalized work and reward settlement.
- Four-validator crash/restart and catch-up tests with quorum-based finalization.
- PyTorch training/export, integer QMLP verification, ONNX experiments and reproducible research reports.
- Recorded service-only and client-observed-finality timings; **not** directly comparable performance boundaries.
- Research data ZIP with SHA-256 manifest and an independent **archived-data reanalysis** performed on a separate GitHub Actions runner.

## Verified research evidence

The release is created from **one specific successful GitHub Actions `main` run** after all core jobs, full Docker testnet and separate evidence audit have passed. The attached files are generated within that same run:

- `aivoblock-research-evidence.zip`: allowlisted source artifacts, 270 observed chain tasks (3 configurations × 3 launches × 30 requests), 90 CPU service requests, 90 trained QMLP finalized-block records, statistical summaries and an integrity manifest.
- `independent-audit.json`: independent reanalysis of the ZIP, checking hashes, experiment identities, recorded phase durations and recomputed descriptive statistics.

**Reproduce the analysis:**

```bash
git clone https://github.com/jihadelsayed/AivoBlock.git
cd AivoBlock
git checkout v0.1.0-research-prototype
python3 scripts/package_research_evidence.py verify aivoblock-research-evidence.zip
python3 scripts/audit_public_evidence.py --archive aivoblock-research-evidence.zip --out independent-audit-recomputed.json
```

The ZIP is obtained from this release's attached assets. Re-running the underlying live experiments requires Docker Compose v2 and Python 3.11+; follow [the experiment guide](https://github.com/jihadelsayed/AivoBlock/blob/v0.1.0-research-prototype/docs/research-reproducibility-package.md) and [private-testnet guide](https://github.com/jihadelsayed/AivoBlock/blob/v0.1.0-research-prototype/docs/testnet.md). New runs may produce different timings.

## Critical scientific and security limitations

- Permissioned, small private testnet only: **no permissionless Sybil resistance**, verified public mainnet, production security guarantee or third-party penetration-test certification.
- Correctness relies on validators' **full recomputation** of small deterministic integer workloads. This is not a succinct proof, a cryptographic guarantee of arbitrary AI training, or demonstration of economic advantage over proof of work.
- Service results represent **in-process** computations; chain results include CLI submission, workers, network consensus and observation polling. Never infer isolated consensus cost, network cost, AI computation cost, throughput superiority or speedup ratios from these unmatched boundaries.
- Independent data reanalysis is not an independent rerun of the experiments on different hardware or peer review. Each experiment has 30 measurements per fresh launch, not 90 fully independent deployments.
- The Sayed Token in the private network is a **test ledger asset**, not an offer of financial value.
