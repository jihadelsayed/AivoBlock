# arXiv cs.DC — Endorsement Outreach (Unsent Draft)

**No endorsement has been confirmed. Do not send a mass mailing.** Start by finding an eligible researcher familiar with distributed systems; an eligible UAB professor is a reasonable first contact.

## Steps

1. From your signed-in arXiv submission flow, select `cs.DC` and obtain your official endorsement request email/link and **six-character code** if one is issued. Do not create a code or invent an endorsement link.
2. Check likely researchers through arXiv's **Which authors of this paper are endorsers?** link. A university professor is **not necessarily eligible** to endorse.
3. Send a small number of individualized messages with the full draft and relevant GitHub evidence, if appropriate. arXiv cautions against emailing large numbers of endorsers or repeatedly contacting the same person.
4. Give the researcher the authentic request link/code received from arXiv. Only the researcher can choose to endorse you. **Endorsement does not make them a coauthor or transfer ownership.**
5. Leave the repo's endorsement status unverified until arXiv confirms the account/category eligibility.
